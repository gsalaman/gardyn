# Design Notes for Gardyn Trellis

Must be able to lift this off with the gardyn so that Alli can access the tank for maintenence.  That means no bolting into the wall or setting on floor.  I think this means we bolt a cross-piece (adjustable?) across the metal brackets, and then hang the hexes from it.  Some sort of suppport at the bottom.  Would also be nice to have the cross-piece adjustable in length....maybe also the "outer" hanger pieces so that we can dynamically change the distance of the hexes from the pods.  Hmmm..and for the outers, maybe even have them adjustable in angle?

Pod spacing:  8", or 4" between angled pods

Alli wants "cross bars" of hex in the middle of the pods.

Four rows of trellis:
* 2 inners have "rotated" hexes
* Outers have some sort of spacer.  Salamanders?
